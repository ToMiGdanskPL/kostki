# 🎲 Kostki by ToMi

Przeglądarkowa gra logiczna typu SameGame z wbudowanym odtwarzaczem internetowych stacji radiowych.

## 📖 Opis

Kostki by ToMi to dynamiczna gra logiczna, w której zadaniem gracza jest usuwanie grup kolorowych kostek z planszy. Każda kolejna runda zwiększa poziom trudności poprzez dodanie nowych kolorów.

Podczas gry można słuchać ulubionych stacji radiowych dzięki wbudowanemu odtwarzaczowi online.

---

## ✨ Funkcje

### 🎮 Gra
- Usuwanie grup minimum 2 kostek tego samego koloru
- System rund
- Rosnący poziom trudności
- Grawitacja kostek
- Przesuwanie pustych kolumn
- Efekt 🔥 COMBO
- Pasek postępu rundy
- Licznik czasu
- Ranking TOP 10

### 🆘 Koła ratunkowe
- ⏱️ Wyłącz czas
- 🔨 Młotek
- 🔀 Mieszaj planszę

### 🏆 Ranking
- Zapisywanie wyników w LocalStorage
- TOP 10 najlepszych graczy
- Zapis daty i godziny wyniku
- Oznaczenie ∞ dla gry bez limitu czasu

### 📻 Radio Online
- Odtwarzanie stacji internetowych
- Następna / poprzednia stacja
- Integracja z Media Session API
- Obsługa Dynamic Island
- Sterowanie z ekranu blokady iOS

---

## 🎯 Zasady gry

1. Kliknij grupę minimum 2 połączonych kostek.
2. Usuń co najmniej 90% planszy.
3. Przejdź do kolejnej rundy.
4. Zdobywaj jak najwięcej punktów.
5. Traf do rankingu TOP 10.
